## Resumo do Sistema

O GoMobi é um sistema inteligente de monitoramento ferroviário desenvolvido para auxiliar operadores, técnicos e administradores no acompanhamento da frota ferroviária em tempo real. A plataforma permite visualizar trens, sensores, alertas e indicadores operacionais por meio de uma interface moderna e intuitiva. Seu diferencial está na centralização das informações, facilitando a tomada de decisões rápidas e aumentando a segurança das operações ferroviárias.

# Seção 5 — Fluxos de navegação do usuário

## Fluxo 1 — Cadastrar-se e acessar o sistema

**Perfil:** Novo usuário

1. Tela de Login
2. Clicar em "Criar Conta"
3. Tela de Cadastro
4. Preencher informações
5. Clicar em "Cadastrar"
6. Retornar para Login
7. Fazer Login
8. Acessar Dashboard

---

## Fluxo 2 — Operador monitora um trem

**Perfil:** Operador

1. Login
2. Dashboard
3. Selecionar um trem
4. Abrir tela de Monitoramento
5. Visualizar status dos sensores
6. Consultar detalhes do trem

---

## Fluxo 3 — Operador verifica alerta crítico

**Perfil:** Operador

1. Login
2. Dashboard
3. Identificar alerta crítico
4. Abrir detalhes do trem afetado
5. Verificar sensor responsável
6. Tomar ação corretiva

---

## Fluxo 4 — Técnico consulta sensores

**Perfil:** Técnico

1. Login
2. Menu Sensores
3. Visualizar sensores cadastrados
4. Filtrar por status
5. Analisar informações
6. Atualizar dados do sensor

---

## Fluxo 5 — Encerrar sessão

**Perfil:** Todos os usuários

1. Acessar menu lateral
2. Clicar em "Sair"
3. Sistema encerra sessão
4. Retorna para Login
